# Project Statement

## 1. Problem Statement

Many people do not know approximately how many calories their body needs in a day. Calculating calorie requirements manually can involve different formulas and activity levels, which can be confusing.

The Calorie Calculator is developed as a simple Java-based application that takes basic information from the user and calculates their Basal Metabolic Rate (BMR) and estimated daily calorie requirement.

## 2. Scope of the Project

The scope of this project includes:

- Taking user details such as gender, age, weight, and height.
- Taking the user's activity level.
- Calculating the user's BMR.
- Estimating the daily calorie requirement based on the activity level.
- Displaying the calculated results in the console.

The project is currently designed as a console-based Java application. It can be extended in the future with a graphical interface, additional health-related calculations, and data storage.

## 3. Target Users

The application can be used by:

- People who want to get an estimate of their daily calorie requirements.
- Students learning about calorie calculations and Java programming.
- Beginners who want a simple tool for understanding BMR and calorie requirements.
- Anyone interested in getting a basic estimate based on their age, gender, height, weight, and activity level.

## 4. High-Level Features

The main features of the project are:

- **User Input:** Collects gender, age, weight, height, and activity level.
- **BMR Calculation:** Calculates the user's Basal Metabolic Rate.
- **Activity-Based Calculation:** Estimates daily calorie needs according to the selected activity level.
- **Result Display:** Shows the calculated BMR and estimated daily calorie requirement.
- **Simple Console Interface:** Allows the user to interact with the application through the terminal.
- **Modular Structure:** Different classes are used for handling user input, storing data, performing calculations, and displaying results.
